# 초기 콘텐츠와 이미지

- 참고 페이지: https://linktr.ee/Orina0
- 공개 페이지에서 확인한 프로필 이름과 Instagram/TikTok/YouTube 목적지 주소를 초기 데이터에 사용했다.
- 소개 문장, 카드 설명, 푸터 문구는 페이지 구성을 위한 수정 가능한 샘플이다. 특정 활동·실적을 보증하는 내용이 아니다.
- `avatar.svg`, `featured.svg`, `favicon.svg`는 이 프로젝트를 위해 코드로 작성한 자체 벡터 샘플이다. 원본 페이지의 캐릭터 이미지를 복사하지 않았다.
- `og-image.png`는 `featured.svg`를 1200×630으로 변환한 공유용 이미지다.
- SNS 아이콘은 외부 폰트/스크립트 없이 인라인 SVG로 표시한다.

운영할 브랜드의 정식 이미지가 준비되면 `public/media/`에 넣고 해당 섹션 설정 파일의 이미지 경로를 교체한다. 공유 이미지·파비콘은 `content/site.json`에서 관리한다. 원본의 이미지/글꼴/문구를 사용할 때는 운영자가 사용 범위를 확인한다.

`tests/fixtures/products.json`의 상품명·브랜드·주소는 검색/화면 검증을 위한 예시이며 실제 광고 상품이 아니다. 운영 상품 목록에 자동으로 연결하지 않는다.
